Gate-based circuits, hardware-aware

Bloqade Digital

Program gate-based computation for reconfigurable neutral atom architectures. Extends QASM2 with parallelism and global gates, and ships compiler passes, emulation and code generation.

Explore the digital API → The original analog SDK

Bloqade Analog

Build, analyze and run analog programs on QuEra’s cloud-accessible "Aquila" hardware. Everything from the classic Bloqade lives on under the bloqade.analog namespace.

Explore the analog API → A hub of composable eDSLs

Built on Kirin

Bloqade is a hub of embedded domain-specific languages built on Kirin, the Kernel Intermediate Representation Infrastructure — hybrid, kernel-based, and made for co-design.
